# Haven | Property Maintenance Assistant
A two-state JavaScript app for tenants. Describe a problem, classify it, select urgency and submit to a local confirmation. Everything runs in the browser. Refreshing or starting another report clears the current report.

## Open in VS Code
1. Extract the ZIP. Open the **Haven** folder (the one containing index.html) with File > Open Folder.
2. On Windows with Microsoft Edge, press F5 and choose **Open Haven in Edge**. Alternatively, open index.html directly in any modern browser. No installs, API keys, or build step.
3. Try “The kitchen tap has been dripping since last night.” Choose Plumbing and Soon. Submit, compare all three values, then choose Report another issue.

## Files
- index.html – accessible form and confirmation markup.
- style.css – desktop grid, mobile layout, typography, focus states.
- app.js – validation, character count, summary and restart.
- assets/homes.svg – original vector streetscape created for this project. System fonts, no third-party assets.
- docs/ – screenshots captured from the working app and illustrated report.
- design/ – editable SVG desktop and mobile boards for both screens.

## Figma handoff
Drag the four SVGs into a new Figma Design file. Put each board into a frame that matches its dimensions. Connect Submit report to the corresponding confirmation frame using On click > Navigate to. Connect Report another issue back. Test both flows in Present mode. Share a view-only link accessible to your instructor and test that link while signed out.

## Publish with GitHub Pages
Create a public repository in your own GitHub account. Upload the contents of Haven so index.html sits at repository root. Commit to main. Under repository Settings > Pages, configure deployment from the main branch and root folder. Open the published address shown by GitHub and repeat the sample flow. Share the repository URL and the deployed site URL separately.
